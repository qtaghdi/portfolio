# 프로젝트 이미지 전체 점검

검토일: 2026-11-01 (Asia/Seoul).

## 운영 배포에서 확인한 문제

운영 주소 `https://park-sangmin.vercel.app/`는 Vercel 배포 `dpl_ECJB9x1jYgrPzcsYx91pUAoTxry1`, Git 커밋 `15c046a62c385ea9795eac86136a4c4e707cd6ec`를 가리킵니다. 최근 로컬 이미지 추가와 메인 미리보기 변경이 반영되지 않은 버전입니다.

운영 주소를 실제 브라우저로 열어 홈과 프로젝트 상세 14개를 확인했습니다. 홈에는 프로젝트 아이콘만 있고 대표 이미지가 없습니다. 상세 페이지는 다섯 프로젝트의 실제 이미지와 Boundra 재현 화면만 표시하며, 나머지 여덟 프로젝트에는 대표 비주얼이 없습니다. 검사한 이미지 파일 자체는 모두 정상적으로 불러왔습니다. 결과는 [운영 이미지 점검 데이터](image-audit-production-2026-11-01.json)에 있습니다.

Boundra는 이미지 요청 실패가 아니라 고정된 레이아웃에서 큰 제목이 옆 영역에 잘리는 문제였습니다. [수정 전](design/image-audit-2026-11-01/boundra-before.png)에서 확인할 수 있습니다.

## 수정 내용과 실제 화면의 구분

홈의 14개 프로젝트 모두 대표 이미지를 표시합니다. 실제 캡처가 있는 여덟 프로젝트는 기존 원본 이미지를 그대로 사용합니다. 디자인 시스템, Notiiv, 인트라넷, document-workspace, OWKR, Chorus, Rust with TypeScript, Apple Music Discord Presence입니다. 각각의 캡션에 공개 화면, 로컬 데모 또는 테스트 데이터 조건을 유지합니다.

실제 제품 캡처가 없는 Boundra, 홈페이지, 점주로, Marker, Kivra, Echo 여섯 프로젝트에는 구현 구조를 설명하는 SVG 다이어그램을 추가했습니다. 모두 실제 제품 화면이 아님을 이미지와 캡션에 명시했습니다. 캡처 자료가 모두 확보되었다는 뜻은 아닙니다. 홈페이지는 후속 작업자의 현재 메인 디자인을 재사용하지 않고 이전 구현의 담당 범위를 설명합니다.

상세 페이지의 여덟 원본 캡처 배치는 유지하고, 이미지가 없던 여섯 프로젝트에는 구조 다이어그램을 연결했습니다. Boundra의 고정 레이아웃을 대체해 제목이 잘리지 않게 하고, 재현 화면에 섞여 있던 과거 성능 수치는 제거했습니다. [수정 후](design/image-audit-2026-11-01/boundra-after.png), [모바일](design/image-audit-2026-11-01/boundra-mobile.png).

## 검증과 배포 상태

- 정적 빌드 30개 경로 통과.
- 원본 이미지, 다이어그램 구분, 홈의 14개 대표 이미지, 한영 페이지, 모바일·데스크톱 배치 등 기존·확장 검사 56개 통과.
- 추가 전체 검사 2개 통과. 프로젝트 상세 14개를 한국어·영어와 데스크톱·모바일의 56개 조합에서 열어 정상 응답, 이미지 디코딩과 가로 넘침을 확인했습니다.
- 이미지 없는 상세 페이지가 다시 생기면 실패하는 검사를 추가했습니다.
- 운영 배포는 변경하지 않았습니다. 위 통과 결과는 수정한 로컬 빌드에 대한 결과입니다.
