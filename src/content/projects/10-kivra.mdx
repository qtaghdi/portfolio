## Problem

개발 중 발견한 오류와 해결 과정은 터미널, IDE, 메신저와 개인 메모에 흩어집니다. 비슷한 문제가 다시 생기면 결과보다 당시의 실행 맥락을 찾는 데 시간이 더 걸립니다.

## Approach

### 1. Shared Memory Protocol

Kivra는 프로젝트별 실행 로그, 오류, 해결 노트를 로컬 데스크톱 앱에 모으고, VS Code와 JetBrains 플러그인이 같은 언어 중립 프로토콜로 접근하도록 설계했습니다. 편집기별 기능을 각각 다시 만드는 대신, 캡처와 조회의 계약을 공통화하는 데 집중했습니다.

## Result

현재는 제품 가설과 기본 통합을 검증한 프로토타입 단계입니다. 포트폴리오에서는 완성된 성과로 과장하지 않고, 서로 다른 개발 환경을 하나의 기억 모델로 연결한 설계 실험으로 소개합니다.
